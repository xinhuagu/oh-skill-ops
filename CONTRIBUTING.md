# Contributing

Oh SkillOps is currently shaping its project direction. Contributions should make the project clearer, more testable, or more useful for teams managing agent skills.

## Useful contributions

- Better skill writing examples.
- Bad examples with clear explanations.
- Governance metadata proposals.
- Evaluation task formats.
- Security and permission review checklists.
- Research notes with sources.

## Style

- Prefer concise, procedural writing.
- Avoid broad claims without evidence.
- Keep examples small enough to review.
- Separate runtime skill instructions from explanatory documentation.

## Review standard

Changes should answer at least one of these questions:

- Does this help people write better skills?
- Does this help teams manage skills safely?
- Does this help skills improve from feedback without uncontrolled mutation?
